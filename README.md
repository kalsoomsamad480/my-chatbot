🤖 Aria - AI Chatbot

A smart AI chatbot built with Python, Groq API, and Streamlit.

  Features

- 💬 Real time AI conversation
- 🎭 Multiple personalities (Assistant, Teacher, Doctor, Friend, Business Advisor)
- 👤 Personalized greetings with your name
- 🗑️ Clear chat button
- 📥 Download chat history
- 📊 Message counter
- 🎨 Clean and professional UI

 Built With
- Python
- Streamlit
- Groq API
- LLaMA 3.3 70B model

## 🚀 Live Demo

[Click here to try the chatbot](https://aria-chatbot.streamlit.app)
How to Run Locally

1. Clone the repository
2. Install dependencies
3. Add your Groq API key
4. Run the app

📦 Installation

```bash
pip install streamlit groq
streamlit run chatbot.py
```

🔑 API Key Setup

Get your free API key from [Groq Console](https://console.groq.com)
